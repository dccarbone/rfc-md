# RFCs

RFCs are authored in Markdown and reviewed through GitHub pull requests.

The canonical path for an RFC is:

```txt
rfcs/<year>/<slug>/rfc.md
```

Example:

```txt
rfcs/2026/application-logs-standardization/rfc.md
```

Use `rfcs/_template/rfc.md` when creating a new RFC.

This README explains the folder convention only. RFC indexes and status views
should be generated by Backstage from RFC frontmatter.
